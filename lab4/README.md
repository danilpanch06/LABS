# Расчёт времени сушки влажного материала (Вариант 10)

Модульное консольное приложение на Python для расчёта массы удаляемой влаги, времени сушки и классификации процесса.

## Требования к среде
- Python 3.10 или выше.

## Запуск программы
- **В VS Code:** откройте папку проекта и нажмите `F5`.
- **В терминале:** `python main.py`

## Запуск тестов
- В терминале: `python -m unittest tests -v`

## Расчётные формулы
- Масса удаляемой воды: $m_w = \frac{m \cdot (w_1 - w_2)}{100 - w_2}$, кг
- Время сушки: $\tau = \frac{1}{k} \cdot \ln\left(\frac{w_1}{w_2}\right)$, ч

## Материалы и коэффициенты скорости сушки ($k$)
| Пункт меню | Материал | Коэффициент $k$, 1/ч |
| :--- | :--- | :--- |
| 1 | Древесина | 0.008 |
| 2 | Керамика | 0.004 |
| 3 | Зерно | 0.012 |

## Допустимые диапазоны входных данных
- Масса влажного материала $m$: `1.0 … 5000.0` кг
- Начальная влажность $w_1$: `5.0 … 60.0` %
- Конечная влажность $w_2$: `0.0 … 30.0` % (при условии $0 < w_2 < w_1$)
- Температура сушильного агента $t$: `40.0 … 250.0` °C

## Классификация процесса сушки по времени ($\tau$)
- $\tau < 2$ ч — **быстрая сушка**
- $2 \le \tau \le 12$ ч — **нормальная сушка**
- $\tau > 12$ ч — **длительная сушка**
